# SkyNoc License Management

Pure PHP 8.3 license/reseller management foundation for cPanel.

## Requirements
- PHP 8.3+
- MySQL/MariaDB
- PDO MySQL
- Apache with mod_rewrite

## Install
1. Create a MySQL database/user in cPanel.
2. Import `database/schema.sql`.
3. Copy `config/config.example.php` to `config/config.php` and set DB values.
4. Point the domain document root to `public_html` or deploy this repository as the web root.
5. Set writable permission for `storage/logs`.
6. Create the first admin using the SQL hash generated by `php -r 'echo password_hash("CHANGE_ME", PASSWORD_DEFAULT), PHP_EOL;'`.

Never store upstream provider passwords. Provider records contain only identification metadata.


## Main Domain Routes

- `https://SkyNoc.Net/` — Public home page
- `https://SkyNoc.Net/login` — Login
- `https://SkyNoc.Net/reseller` — Reseller portal
- `https://SkyNoc.Net/admin` — Admin panel
- `https://SkyNoc.Net/api/v1/` — Reseller API
- `https://SkyNoc.Net/api-docs` — API documentation

Legacy `.php` routes redirect to the clean URLs.
